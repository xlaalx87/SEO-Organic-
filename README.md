# Ghidul Tutunului

Blog static (HTML + CSS) cu articole informative despre tutunul pentru rulat. Site administrat de proprietarii Tutunselect.ro, Tutuntocat.ro și Tutuncurat.ro, cu mențiune de transparență și notificare 18+ pe fiecare pagină.

## Structură
- `index.html` — lista de articole
- `magazine.html` — pagina „Magazinele noastre" (singurul link în footer către magazine)
- `articole/` — articolele; maximum un link către un magazin per articol, cu anchor descriptiv
- `sitemap.xml`, `robots.txt`

## Publicare pe GitHub Pages
1. În repo: **Settings → Pages**.
2. La **Source** alege **Deploy from a branch**, branch `main`, folder `/ (root)`, apoi **Save**.
3. Site-ul apare la `https://xlaalx87.github.io/SEO-Organic-/`.
4. Dacă folosești un domeniu propriu, înlocuiește `https://xlaalx87.github.io/SEO-Organic-` în `sitemap.xml`, `robots.txt` și în tagurile canonical.
